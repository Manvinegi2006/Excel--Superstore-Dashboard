# 📊 Superstore Executive Performance Dashboard (Microsoft Excel)

An end-to-end data analytics project created in Microsoft Excel using a dataset of 9,994 transaction records spanning from 2020 to 2023. This project evaluates business health, profit drivers, regional discounting strategies, and customer trends to provide actionable business recommendations.

---

## 📌 Project Overview
* **Objective:** Clean, prepare, and transform raw transactional data into an interactive executive dashboard to uncover key revenue drivers and profit drainers.
* **Tools Used:** Microsoft Excel (Data Preparation, Helper Column Formulas, Pivot Tables PT1–PT9, PivotCharts, KPI Cards, Interactive Slicers).

---

## 🛠️ Data Quality & Preparation
1. **Integrity Checks:** Verified **9,994 orders** with 0 missing values and 0 duplicate rows across Orders, Returns, and People datasets.
2. **Feature Engineering:**
   * `Order Year`: Calculated using `=YEAR([@[Order Date]])` for global timeline filtering.
   * `Discount Bracket`: Categorized continuous discounts into strategy tiers (`0%`, `1-20%`, `21-50%`, `51-80%`) to measure profit impact.

---
